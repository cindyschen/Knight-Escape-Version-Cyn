# Knight Escape Version Cyn

My upgraded version of the Princess Knight Platformer from [Brackeys' Godot Tutorial](https://www.youtube.com/watch?v=LOhfqjmasi0).

New features include:
- Main menu
- Levels menu and selection
- 3 playable levels
- Global coin tracker
- Level exits with fade transition
- Double jump mechanism
- Pause menu
- More sound effects!

Assets used are from [Brackeys' Platformer Bundle](https://brackeysgames.itch.io/brackeys-platformer-bundle)
